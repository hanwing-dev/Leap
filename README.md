# Leap 1.0.0 使用手册

Leap 是 Hanyx 开发的 Windows 学习工作台。作业列表、课程视频、签到提醒和平台登录集中在一个窗口。正式版本从 **1.0.0** 开始。此前以 AI Homework Assistant、courseX 和 Leap 命名的构建在[开发历程](HISTORY.md)中保留原版本号和 Beta 标记。

## 下载与安装

1. 从 [Releases](https://github.com/hyx-aero-ai/Leap/releases) 下载 `Leap_1.0.0_windows-x64.msi`。需要 Windows 10 或 11（64 位）以及 Microsoft Edge WebView2 Runtime。若电脑缺少 WebView2，请先从 [Microsoft 官网](https://developer.microsoft.com/microsoft-edge/webview2/)安装。
2. 可先在下载目录打开 PowerShell，运行 `Get-FileHash .\Leap_1.0.0_windows-x64.msi -Algorithm SHA256`，将输出和本次发布附带的 `SHA256.txt` 对照。SHA-256 可用于验证下载的文件是否一致。MSI 未签名，Windows 可能显示未知发布者。
3. 双击 MSI，完成后在开始菜单搜索 **Leap**。若之前安装了 Beta，升级前先退出旧版，并在 **设置 → 数据备份**导出备份。设置、登录状态和缓存取决于旧版使用的数据目录和本机账号，若未继承请重新登录。

## 第一次打开

1. 打开 **设置 → 平台登录**，分别登录需要使用的学习通或雨课堂。请在平台页中完成扫码、密码或验证码。外部浏览器与软件内嵌页面使用各自的登录状态。
2. 登录后回到 **作业列表**，点击刷新。启动时也会扫描。选择平台可切换下方的任务列表。扫描卡片分别显示两个平台的进度。
3. 只使用列表、播放和签到提醒时，无需配置 AI。需要题目辅助时，在 **设置 → 模型设置**选择服务商，填入自己的 API 地址、模型及 Key，然后点击 **测试连接**。连接测试和生成可能计费。图片题需要支持视觉的模型并开启图片输入。听力转写与生成答案是两个步骤，个别音频需手动导入。

## 查看和处理作业

- 用「待办、待核对、已完成、全部」和搜索定位任务。「待核对」表示日期、状态或目录还需复查。信息请以教学平台为准。
- 「去完成」会打开对应的平台任务页面。页面工具可读取题目，在已适配的页面上生成和填入答案。生成结果请逐题检查。正式考试请遵照课程规定。填入后在平台确认是否保存或提交成功。
- 要上传录音或其他附件的题目，请在平台上传。图片或听力无法读取时，可在对应题目中手动提供原图、音频或文字。
- 若卡片显示部分目录或页面待核对，展开扫描详情，查看受影响的课程并重读。即使扫描结束，也可能还有待核对页面。

## 课程视频与小窗

- 打开 **刷课**，选择平台和课程，再打开视频或从当前课程开始连续播放。暂停、进度和速度可在悬浮小窗查看。倍速以网页播放器实际提供的档位为准。
- 视频结束时，课程完成状态以平台确认结果为准。如果断网、会话过期或需要交互，打开播放器查看提示，重新登录后再继续。
- 扫描、视频播放和签到可能共用学习通会话。遇到会话占用时，可先暂停播放，检查签到后再恢复。

## 签到与通知

- 打开 **签到 → 检查签到**，查看学习通的活动。按平台要求本人完成定位、扫码、手势等签到验证。
- 开启后台检查后，软件运行时会检查并发送 Windows 通知。关闭动作可收起到托盘，便于继续检查。选择退出软件会停止提醒。
- 如果检查失败，先看平台登录状态，之后重试。需要反馈时，请提供可复现的步骤和脱敏的诊断信息。

## 外观、备份与排查

- **视图**可切换浅色与深色。**设置 → 桌面与窗口**可调整关窗行为、动效强度和减少动态效果。开启减少动态效果后，动效档位的位移效果停用。
- **设置 → 数据备份**可导出和恢复数据。API Key 由当前 Windows 用户加密保存，备份不含密钥。在另一台电脑恢复后，请重新登录并填写 Key。
- 扫描为空时，先确认平台、课程和筛选条件，再看扫描详情。截止时间待核对时，仍可在「全部」或「待核对」查看任务。教学平台改版、会话过期或网络异常都可能影响扫描。
- 首次公开版的验收范围见发行说明。遇到问题可在 [GitHub Issues](https://github.com/hyx-aero-ai/Leap/issues)反馈，附上版本、Windows 版本、复现步骤和脱敏截图。请勿附上密码、API Key、登录二维码或未脱敏的课程与考卷信息。
